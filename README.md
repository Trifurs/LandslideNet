# LandslideNet

Large-scale landslide susceptibility mapping with leakage-safe continuous
regional hold-out validation.

## Project layout

Only three root programs are used:

1. `1_data_processing.py` builds and freezes label-independent continuous
   physiographic macro-regions.
2. `2_model_train.py` runs regional hold-out training and the DWSS/random
   negative-sampling control.
3. `3_model_predict.py` generates full-domain or OOF susceptibility maps.

The proposed network is isolated in `landslidenet/model.py`. Comparison models
are isolated in `Tools/model_comparisons/`. Reusable pipeline code is in
`utils/`. The adapted interpretation workflow remains in `Tools/SHAP/`.
Publication-ready training curves are generated by
`Tools/plot_training_curves.py`.

## Reviewer comments 1 and 2

For every outer fold, one complete continuous macro-region is test-only. A
second complete region is validation-only, and all remaining regions are used
for inner training.

- Continuous normalization and categorical frequency-ratio encoding are fitted
  from inner-training regions only.
- DWSS KDE prototypes, density scale, eligibility rule, Jenks breaks, and
  stratum weights are recalculated independently inside every fold.
- Test-region context is masked out of training patches.
- Model/epoch and threshold selection use the validation region only.
- The outer test region is evaluated once after all choices are frozen.
- DWSS and random arms share positives, candidate pool, feature transformer,
  model seed, validation negatives, test negatives, and metric code. Only the
  training-negative selection rule changes.
- Every fold writes `paired_sampling_control_audit.json` with reproducible
  SHA-256 fingerprints for those shared inputs and explicit equality checks.
- ROC-AUC, PR-AUC, F1, Kappa, Precision, and Recall are reported with spatial
  tile-block Bootstrap intervals. Equal-region macro means are primary.

The K=5 raster currently contains `9508, 41, 790, 47, 21` factor-valid positive
pixels. Low-support regions are retained and flagged rather than deleted or
used to redraw boundaries. See `docs/REVIEWER_PROTOCOL.md`.

## Model selection in XML

Edit this one item in `Landslide_susceptibility_mapping.xml`:

```xml
<param><name>model</name><value>landslidenet</value></param>
```

Accepted values include:

- one model: `landslidenet`, `random_forest`, `lightgbm`, `dbpfnet`, etc.;
- a list: `landslidenet,random_forest,lightgbm`;
- a group: `machine_learning`, `deep_learning`, `ablation`, or `proposed`;
- `all`: runs all registered models sequentially under the same folds.

`--models ...` overrides the XML selection. The legacy `--suite` interface is
retained for compatibility.

## Full-domain mapping

`3_model_predict.py` defaults to `full`:

- every deep model uses multi-stride median fusion (MSMF);
- every classical model uses direct per-pixel inference and never calls MSMF;
- fold models are combined by a pixel-wise median;
- full-domain maps are deployment/CV-ensemble products and are not used to
  report held-out accuracy.

MSMF enforces an odd number of at least five non-multiple strides. For a
512-pixel window, the default strides are `384, 432, 457, 313, 337`, matching
the upstream overlaps `128, 80, 55, 199, 175`.

Use `--map-type oof` only when an honest cross-fitted regional validation map is
needed. Each OOF region is predicted only by the fold in which that whole
region was the outer test region.

## Run in order

```bash
cd /home/whu/桌面/myCode/LandslideNet

# 0. Create/update the actual environment.
conda env update -n landslidenet -f environment.yml

# Optional verification.
conda run -n landslidenet python -m unittest discover -s tests -v

# 1. Build/check K=4, K=5 and K=6 terrain macro-regions.
conda run -n landslidenet python 1_data_processing.py \
  Landslide_susceptibility_mapping.xml

# 2. Train all manuscript models sequentially.
conda run -n landslidenet python 2_model_train.py \
  Landslide_susceptibility_mapping.xml \
  --models all \
  --output-dir /home/whu/桌面/myResult/LandslideNet/02_experiment

# 3. Generate all selected full-domain maps.
conda run -n landslidenet python 3_model_predict.py \
  /home/whu/桌面/myResult/LandslideNet/02_experiment \
  --models all --sampling-methods dwss random --map-type full
```

If a run is interrupted, repeat the identical command with `--resume`. Use
`--overwrite` only when intentionally replacing full-map outputs.

Useful audit commands:

```bash

```

## Training curves

Every newly trained deep model writes an incremental
`training_history.csv`. The plotting tool also reads epoch records from old
`*.log` files, so existing experiments do not need to be rerun.

```bash
# Manuscript figure: equal-fold mean and 95% CI for LandslideNet/DWSS.
conda run -n landslidenet python -m Tools.plot_training_curves \
  /home/whu/桌面/myResult/LandslideNet/02_experiment \
  --model landslidenet --sampling-method dwss

# One fold only.
conda run -n landslidenet python -m Tools.plot_training_curves \
  /home/whu/桌面/myResult/LandslideNet/02_experiment/Fold_1_TestRegion_1/DWSS/Model_landslidenet

# Write the aggregate figure and every fold figure.
conda run -n landslidenet python -m Tools.plot_training_curves \
  /home/whu/桌面/myResult/LandslideNet/02_experiment \
  --model landslidenet --sampling-method dwss --mode both
```

PNG (600 dpi) and vector PDF are produced by default. Curves are not smoothed
unless `--smooth-window N` is explicitly supplied; when smoothing is requested,
the raw curves remain visible underneath.

## SHAP

SHAP is optional and runs after training. `Tools/SHAP/SHAP.xml` is configured
for the completed LandslideNet/RANDOM experiment and writes the two separately
usable Fig. 18 panels (`Figure18a_Global_Feature_Importance` and
`Figure18b_SHAP_Summary_Plot`) as PNG/PDF files to its configured output path:

```bash
conda run -n landslidenet python -m Tools.SHAP.shap_analysis \
  Tools/SHAP/SHAP.xml --overwrite
```

Each fold uses class-balanced inner-training patches as its SHAP background
and explains a class-balanced subset of its frozen outer-test samples. SHAP is
descriptive attribution, not independent validation evidence. The global
importance chart is an equal-region mean; the SHAP summary plot uses a balanced
pixel sample from every outer test region. Add `--include-local-maps` only when
the optional 20-factor local-attribution atlases are also needed.

For the manuscript Chapter 7 four-type comparison (Fig. 20), use the separate
cross-fitted type SHAP tool.  It writes the complete comparison and its four
individually usable panels to `/home/whu/桌面/myResult/LandslideNet/02_experiment/SHAP/Type`:

```bash
conda run -n landslidenet python -m Tools.SHAP.type_shap_analysis \
  Tools/SHAP/Type_SHAP.xml --overwrite
```

## DWSS versus Random sampling control

The reviewer-facing sampling-control tool compares LandslideNet under the two
arms as a paired outer-region experiment. It verifies that every held-out test
label/spatial block and every shared-control audit match before writing:

- `Figure_S1_Paired_Regional_Performance`: six DWSS-minus-Random metrics by
  held-out macro-region, with an equal-region mean and 95% region-level CI;
- `Figure_S2_Equal_Region_ROC_PR`: equal-region ROC and precision–recall
  curves, with the full range across regions shaded;
- `Figure_S3_Environmental_Separation`: an environmental-distance diagnostic
  for the selected negatives in each fold's frozen feature space;
- `Figure_S4_Training_Negative_Distribution`: the shared training positives
  and the different DWSS/Random negative selections in every fold.

```bash
conda run -n landslidenet python Tools/compare_sampling_methods.py \
  Tools/Sampling_Comparison.xml --overwrite
```

All three root tasks show live progress by default. Add `--no-progress` for
logs or non-interactive terminals.
